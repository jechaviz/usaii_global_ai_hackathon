# USAII Global AI Hackathon 2026 Product Core

Vlang core for `AI Study-to-Work Coach`, the student-partner package for USAII
Global AI Hackathon 2026.

## Commands

```powershell
v run .\cmd\usaii generate
v run .\cmd\usaii plan --json
v run .\cmd\usaii judge
v run .\cmd\usaii qa
v run .\cmd\usaii form --dry-run
v run .\cmd\usaii serve --port 4197
```

The core keeps private student eligibility data out of generated artifacts.
External qualifier and Devpost submissions remain gated to an authorized student
team session.
